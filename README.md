## Installation & Setup

1. Download the latest `DAVBO-POS-v1.0.0.zip` from the [Releases](../../releases) section.
2. Extract the ZIP folder on your computer.
3. Open `db_setup.sql` in SQL Server Management Studio (SSMS) and execute it to generate the database.
4. Open `DAVBO-POS.exe.config` and adjust the connection string to match your local SQL Server instance if needed.
5. Launch `DAVBO-POS.exe`.
